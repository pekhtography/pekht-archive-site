# Portfolio validation artifacts

## 0.2.0 reference baseline

`portfolio-validation-0.2.0-baseline/` is retained in this repository as an isolated, historical validation artifact. Its files are covered by the SHA-256 manifest at `portfolio-validation-0.2.1/BASELINE-0.2.0-SHA256.txt` and must remain byte-for-byte unchanged when validating the 0.2.1 package.

The baseline README preserves the wording and state of the original 0.2.0 artifact at the time it was prepared. Its statement that the artifact was not committed to the repository is historical; it is not a description of the current repository layout.

The baseline is not installed into the site runtime and is not part of the production application. Explanatory documentation about the current repository layout belongs in this file, outside the immutable baseline directory.
